# USP Student Well-Being Questionnaire

## Open in Visual Studio Code

1. Open the `usp-questionnaire` folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

This version saves test responses in the current browser using `localStorage`. It must not be used for real research data yet. Connect a secured backend such as Supabase only after the questionnaire, consent wording, counselling details, and ethics process are approved.

Before publishing, replace the placeholder counselling details in `index.html` with verified USP contact information.
